Model Registry

Think:
```
                   Model Registry

             ┌───────────┼───────────┐
             ↓           ↓           ↓
          Model v1    Model v2    Model v3
             │
          Staging
             │
          Production
```
Learn:
```
model versions
model artifacts
metadata
model lineage
staging
production
promotion
rollback
```
